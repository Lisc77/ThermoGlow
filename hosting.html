Web Hosting y dominios

Para que una página se pueda visitar por internet, sus archivos necesitan estar alojados y tener una dirección.

¿Qué es el hosting?

El hosting o alojamiento web es un servicio que guarda los archivos de un sitio en un servidor conectado a internet. Cuando una persona visita la página, el servidor entrega esos archivos al navegador.

Tipos comunes

  • Compartido: varios sitios utilizan recursos de un mismo servidor.
  • VPS: ofrece recursos virtuales más aislados y configurables.
  • Dedicado: un servidor se destina a un solo cliente.
  • Nube: utiliza infraestructura distribuida para alojar servicios.

¿Qué es un dominio?

El dominio es el nombre que las personas escriben para encontrar un sitio, como ejemplo.com. El sistema DNS ayuda a localizar el servidor asociado con ese nombre.

Partes de un dominio

tienda.ejemplo.com

  • tienda: subdominio.
  • ejemplo: nombre elegido.
  • .com: extensión o dominio de nivel superior.

¿Cómo se publica una página?

1

Preparar

Revisar HTML, CSS, JavaScript e imágenes.

2

Elegir hosting

Seleccionar el servicio adecuado al proyecto.

3

Subir archivos

Publicar la carpeta del sitio en el servidor.

4

Conectar dominio

Configurar el DNS si se utiliza un dominio propio.
