JavaScript

El lenguaje que permite que una página web responda a lo que hace la persona que la visita.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación usado principalmente para agregar comportamiento a las páginas web. Con él se pueden validar formularios, abrir ventanas, cambiar textos, actualizar datos y responder a clics.

HTML, CSS y JavaScript no hacen lo mismo

Tecnología Función Ejemplo
HTML Organiza el contenido. Título, imagen o formulario.
CSS Define la presentación. Colores, tamaño y distribución.
JavaScript Añade comportamiento. Un botón que cambia un mensaje.

Variables, funciones y eventos

  • Variable: guarda un dato, por ejemplo el nombre de un producto.
  • Función: reúne instrucciones que se pueden ejecutar cuando hacen falta.
  • Evento: algo que ocurre, como pulsar un botón o mover el puntero.

Prueba un ejemplo

Pulsa el botón y JavaScript cambiará el texto.

Hola, bienvenido a ThermoGlow.

const boton = document.querySelector("#btnDemo");
boton.addEventListener("click", () => {
  document.querySelector("#mensajeDemo").textContent =
    "¡El botón funciona!";
});

Ventajas y usos comunes

Interactividad

Hace que los controles respondan sin recargar toda la página.

Validación

Ayuda a revisar datos de formularios antes de enviarlos.

Contenido dinámico

Permite actualizar textos, listas y elementos de la interfaz.
