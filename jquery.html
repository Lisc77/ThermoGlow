jQuery

Una biblioteca de JavaScript que simplifica tareas frecuentes, como seleccionar elementos y crear efectos.

¿Qué es y para qué sirve?

jQuery es una biblioteca creada para facilitar el trabajo con JavaScript. Se hizo popular porque ofrecía una sintaxis más corta para recorrer el documento HTML, manejar eventos, modificar elementos y realizar peticiones a servidores.

Su forma más conocida de seleccionar elementos comienza con el signo $. Por ejemplo, $("#aviso") selecciona el elemento que tiene el identificador aviso.

Ventajas y desventajas

Ventajas

  • Sintaxis compacta.
  • Facilita algunos efectos visuales.
  • Fue útil para compatibilidad entre navegadores antiguos.

Desventajas

  • Necesita cargar una biblioteca adicional.
  • Para tareas sencillas, JavaScript moderno puede bastar.
  • Hay que conocer las dependencias del proyecto.

jQuery frente a JavaScript moderno

Hoy, muchas funciones de selección de elementos, eventos y animaciones se pueden realizar directamente con JavaScript. jQuery sigue presente en sitios y sistemas que ya lo utilizan.

Prueba los efectos
