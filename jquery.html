JSON

Un formato de texto sencillo para representar e intercambiar información entre aplicaciones.

¿Qué significa JSON?

JSON viene de JavaScript Object Notation. Aunque su nombre hace referencia a JavaScript, puede utilizarse con muchos lenguajes de programación. Su estructura se basa en pares de clave y valor, objetos y listas.

Reglas básicas

  • Las claves se escriben entre comillas dobles.
  • Los textos también llevan comillas dobles.
  • Los pares clave-valor se separan con comas.
  • Se pueden usar números, cadenas, valores booleanos, null, objetos y arreglos.

Ejemplo de un producto

{
  "producto": "ThermoGlow Classic",
  "capacidadMl": 500,
  "cambiaColor": true,
  "colores": ["azul", "violeta"]
}

Este ejemplo describe un vaso con nombre, capacidad, una característica y una lista de colores.
